# Midnight Watch — Execution Pack

- **Created:** 28 August 2026
- **Version:** O1 Execution Pack / New-Midnight Architecture
- **Umbrella:** Midnight Watch

This folder contains two independently usable execution families:

- **Midnight Watch Runtime**
  - Application-runtime truth.
  - Generated from Midnight Watch Runtime Roadmap O2.

- **Midnight Watch Data**
  - Data architecture and data-runtime truth.
  - Generated from Midnight Watch Data Roadmap O1.

They may be implemented and used separately or together.

The conversational phrase “Midnight Data Watch” refers to the capability standardized in the current documents as **Midnight Watch Data**.

The two execution families preserve separate domain ownership, stable cross-capability references, no direct sibling-database reads, optional combined correlation, and independent degradation/qualification.
